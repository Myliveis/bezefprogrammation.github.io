📘 ClearBudget – 도움말 센터

⭐ 프리미엄 버전 (Premium)

ClearBudget 무료 버전은 고객 수와 거래 수에 제한이 있습니다. 광고를 시청하거나 포인트를 모아 계속 사용할 수 있습니다. 프리미엄 버전의 혜택:
• 고객·거래·영수증을 무제한으로 사용 (평생)
• 모든 광고 완전 제거
• 향후 고급 기능 제공
• 빠른 고객 지원 구매 방법:
• Google Play (Google 계정 + 결제 수단 필요)
• 또는 개발자에게 직접 연락하여 Wish, OMT, 암호화폐 등으로 결제 직접 결제 후 앱에서 입력할 활성화 코드를 받게 됩니다.

👤 개인 정보 페이지

이 페이지에서는 보고서와 영수증에 표시될 이름, 서명, 회사 로고를 설정할 수 있습니다. 언제든지 정보를 수정하여 저장할 수 있습니다. 모든 데이터는 사용자의 기기 안에만 저장되며 외부로 전송되지 않습니다. 원한다면 항목을 비워 익명으로 사용할 수도 있습니다.

💱 통화 설정

사용할 통화를 선택하세요 (USD · EUR · GBP · LBP 또는 기타 현지 통화). 통화를 변경하면 과거 거래 기록이 자동으로 새 통화로 변환됩니다. 모든 보고서도 즉시 업데이트됩니다.

☁️ 백업 및 복원

ClearBudget은 두 가지 백업 방식을 제공합니다: 1) Google Drive 백업: • Google 계정 필요 • 매일 자동 백업 설정 가능 • 수동으로 즉시 백업 생성 • 저장된 최신 백업을 한 번에 복원 2) 수동 백업 (ZIP 파일): • 백업 파일을 어디든 저장 가능 (스마트폰·WhatsApp·이메일·클라우드 등) • 선택한 ZIP 파일에서 데이터 복원 ⚠️ 주의: 복원 시 현재 데이터는 모두 덮어쓰기 됩니다.

👥 고객 페이지

(+) 버튼을 눌러 새 고객을 추가합니다. 전화번호는 선택 사항이지만, 통화나 메시지 전송에 편리합니다. 고객을 길게 누르면 다음 작업 가능: • 정보 수정 • 삭제 • 고객 유형 변경: 일반 – 로컬 USD 고객 – 로컬 고객 USD 공급업체 – 로컬 공급업체 고객 잔액은 거래 내역을 기반으로 자동 계산됩니다.

💼 거래 페이지

지불, 수금, 부채, 구매, 판매 등 모든 거래를 기록할 수 있습니다. 추가 기능:
• WhatsApp 등으로 공유 가능한 PDF 명세서
• 영수증 및 송장 생성
• 생성된 모든 문서는 문서 보관함에 저장

📂 카테고리 페이지

고객 유형별 상세 통계를 표시합니다: 고객 – 공급업체 – 일반 – 로컬 – USD. 확인 가능한 내용: • 받을 금액 총합 • 지불해야 할 금액 총합 • 선택한 통화 기준 표시

📊 보고서 페이지

강력한 분석 기능 포함: • 가장 큰 채무자 • 최고의 고객 • 채무 기간 분석 (오래된 / 신규) • 월별 자금 흐름 통화를 쉽게 변경하고 월별 데이터를 즉시 확인할 수 있습니다.

🧾 문서 및 영수증

사용자가 생성한 모든 문서가 저장됩니다: • 송장 • 지불 영수증 • PDF 명세서 문서를 열고, 공유하고, 삭제할 수 있습니다.

⏰ 알림 페이지

고객마다 특정 알림을 생성할 수 있습니다: • 결제 알림 • 후속 조치 • 마감일 • 특정 고객에 대한 메모 알림 카드에서 직접 WhatsApp 메시지 전송 또는 전화 걸기가 가능합니다.

🔒 보안 설정

PIN 또는 지문 인식을 통해 데이터를 보호할 수 있습니다. 추가 기능:
• PIN 변경
• 스마트 인증 및 생체 복구
• 비상 복구 코드
