📘 ClearBudget – Centre d’Aide

⭐ Version Premium

La version gratuite de ClearBudget limite le nombre de clients et de transactions. Vous pouvez continuer à l’utiliser en regardant des publicités ou en gagnant des points. La version Premium vous offre :
• Clients, transactions et factures illimités à vie • Suppression de toutes les publicités • Fonctionnalités exclusives futures • Support prioritaire Méthodes de paiement :
• Via Google Play (si vous avez un compte Google et une carte de paiement) • Ou en contactant le développeur pour payer via : Whish, OMT, cryptomonnaies, etc. Après paiement direct, vous recevrez un code d’activation à saisir dans l’application.

👤 Informations personnelles

Cette page vous permet de personnaliser vos rapports et factures avec votre nom, votre signature et le logo de votre entreprise. Vous pouvez modifier vos informations à tout moment puis appuyer sur (Enregistrer). Toutes vos données restent uniquement sur votre appareil et ne sont envoyées nulle part. Vous pouvez aussi laisser les champs vides si vous préférez ne pas afficher votre identité.

💱 Paramètres de devise

Sélectionnez la devise que vous souhaitez utiliser dans l’application (USD – EUR – GBP – LBP – ou votre devise locale). Lorsque vous changez de devise, l’application convertit automatiquement toutes les transactions précédentes vers la nouvelle devise. Vous pouvez changer à tout moment et les rapports seront mis à jour instantanément.

☁️ Sauvegarde et restauration

ClearBudget propose deux méthodes de sauvegarde : 1) Sauvegarde Google Drive : • Nécessite une connexion Google • Sauvegarde automatique quotidienne • Sauvegarde manuelle instantanée • Restauration en un clic de la dernière sauvegarde cloud 2) Sauvegarde manuelle (fichier ZIP) : • Exportez vos données n’importe où : téléphone, WhatsApp, email ou tout stockage cloud • Restaurez n’importe quel fichier que vous choisissez ⚠️ Remarque : la restauration supprime vos données actuelles et les remplace par la sauvegarde choisie.

👥 Page des clients

Appuyez sur (+) pour ajouter un nouveau client. Vous pouvez ajouter un nom et un numéro de téléphone — facultatif mais utile pour appeler ou envoyer des messages. Appui long sur un client pour : modifier, supprimer, ou changer son type parmi :
• Général – Général (Local)
• Client USD – Client Local
• Fournisseur USD – Fournisseur Local Le solde de chaque client est calculé automatiquement.

💼 Page des transactions

Enregistrez ici toutes les opérations : paiement, encaissement, dette, achat ou vente. Fonctionnalités supplémentaires :
• Bouton PDF pour générer un relevé prêt à être envoyé via WhatsApp
• Bouton Facture pour créer une facture ou un reçu de paiement
• Tous les documents générés sont sauvegardés automatiquement dans la page Archive

📂 Catégories

Affiche des statistiques détaillées selon le type de client : Clients – Fournisseurs – Général – Local – USD. Vous pouvez voir : • Montants dus • Montants que vous devez • Basé sur la devise choisie (USD – Local)

📊 Rapports

Une page puissante pour analyser votre activité : • Principaux débiteurs • Meilleurs clients • Ancienneté des dettes (anciennes – récentes) • Flux de trésorerie mensuel Vous pouvez changer de devise facilement et naviguer entre les mois.

🧾 Documents et factures

Cette page contient tous les documents que vous avez créés : • Factures • Reçus de paiement • Relevés PDF Vous pouvez rouvrir un document, le partager ou le supprimer.

⏰ Rappels

Créez des rappels liés à n’importe quel client : • Rappel de paiement • Suivi d’une demande • Dates d’échéance • Notes pour un client spécifique Vous pouvez appeler ou envoyer un WhatsApp directement depuis la carte.

🔒 Sécurité

Protégez vos données en activant le verrouillage par code PIN ou empreinte digitale. Options supplémentaires :
• Changer votre PIN
• Récupération via empreinte ou méthode intelligente
• Code de récupération d’urgence
